# Описание задачи

1. Задача: разработать разностную схему для решения многомерного уравнения теплопроводности:
 
    $$\Large \frac{∂u}{∂t} = \alpha_x\frac{∂^2u}{∂x^2} + \alpha_y\frac{∂^2u}{∂y^2} + f(t,x,y)$$

    u – функция условной температуры внутри многомерной области, x и y – координаты,  $f(t,x,y)$ – функция, имитирующая внешнее температурное воздействие.

    Реализовать расчет динамики температуры в некоторой двухмерной области. 

2. Последовательность выполнения работы:

    a.	Задать двумерную область экосистемы (произвольной формы – например, выбрать контур какой-либо страны, водоёма и т.п.).
    
    b.	Провести дискретизацию двухмерной области, построив внутри неё прямоугольную сетку по координатам x и y. 
    
    c.	Разработать численную схему решения задачи теплопроводности, определить характеристики её устойчивости и сходимости. Задать начальное распределение температур в виде матрицы узловых значений температуры на 
    сетке – предусмотреть существенно неравномерное распределение температур.

    d.	Задать функцию внешнего воздействия по контуру моделируемой области в виде:
    $$\large f(t,x,y) = 1 + m\cos(\omega t) \ \ для\ точек\ (x, y) \in Ω - контур\ области$$

    $$\large f(t,x,y) = 0 \ \ для\ прочих\ точек$$
    e.	Используя численную схему решения уравнения, провести процесс моделирования динамики температуры в заданной области.
    
    f.	Оценить сходимость использованной численной схемы.

3. Содержание отчёта.

    a. Вид (картинка) двухмерной области и ее дискретное разбиение.

    b. Шаблон численной схемы.

    c. Математическое представление численной схемы.

    d. Оценка сходимости выбранной численной схемы.

    e. Первый результат вычислений – картина или таблица распределения температур в области в начальный момент времени и на нескольких последовательных временных слоях.

    f. Второй результат вычислений – графики изменения температуры в нескольких выбранных точках области.
